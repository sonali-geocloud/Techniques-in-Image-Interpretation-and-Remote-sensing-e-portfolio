# Sonali Rajput — Geoinformatics Portfolio

Light, professional portfolio for GitHub Pages.

Open `index.html` in a browser to preview. Keep the `assets/images` folder beside it so the portrait, maps and field photographs load correctly.

To publish, upload `index.html` and the complete `assets` folder to the repository root, then enable GitHub Pages in Settings → Pages.

The portfolio includes About Me and academic background, TIIRS projects and reflection, field photographs, skills, and email/LinkedIn/GitHub contact links. Exercise PDF/DOCX download cards have been removed.
